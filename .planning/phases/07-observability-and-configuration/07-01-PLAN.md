<objective>
Decompose `internal/udprepl/repl.go` (1 417 lines mixing socket, event loop, mirror and codec) into `adapter.go`, `socket.go`, `codec.go`, `loop.go` and `mirror.go` in the same package, and relocate the `SentByType` value type into `internal/app/repl` so the exporter no longer imports the socket adapter (OBSV-08, D-08; the first half of OBSV-07's cross-import removal, D-07).

Purpose: the split is mechanical and behavior-free, landing before the metric and lifecycle edits so every later diff is small and reviewable. Moving `SentByType` first is what lets plan 07-03 add the `metrics` depguard deny rule without breaking the build.
Output: five single-responsibility files in `internal/udprepl`, `internal/app/repl/sentbytype.go`, and an unchanged udprepl test suite.
</objective>
