<objective>
Make the remaining metric definitions honest and give the four Phase-4 counters their production surface (OBSV-03, D-05/14.4): count sends only after the socket accepts them, report current Linux RSS, publish listings-dropped/sync-streams-dropped/listed-keys-evicted/notifications-regressed, and state every definition in the Help with a test per definition.

Output: send accounting, the RSS platform split, four new families, rewritten Helps and `TestMetrics_definitions`.
</objective>
