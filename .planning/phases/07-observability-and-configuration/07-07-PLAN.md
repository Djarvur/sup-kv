## Trust Boundaries

| Boundary | Description |
|----------|-------------|

| Operator secrets → startup record | Certificate paths/contents must not leak. |
| Core → adapters/wiring | Lifecycle events cross as typed values, not strings. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-07-20 | Tampering | log injection via handle/run_id | high | mitigate | Handles are structured `slog` values (quoted by the handler), run ids are hex strings, messages are static and capitalized; no field concatenation into `msg`. |
| T-07-21 | Information disclosure | startup config secrets | high | mitigate | The startup record omits certificate/key paths and contents, carrying only `metrics_addr` and `metrics_tls`; the process test asserts the keys are absent. |
| T-07-22 | Denial of service | drift/peer log flood | medium | mitigate | Drift uses the shared per-(node_id, clock_drift) limiter; peer events fire only on real transitions (repeat Hello/alternation emit nothing). |
| T-07-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package is installed. |
</threat_model>
