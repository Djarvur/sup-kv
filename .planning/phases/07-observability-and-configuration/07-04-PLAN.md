## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Signal → process | SIGTERM/SIGINT arrive at any time, including during load and bind. |
| Serve failure → operator | A listener fault must be visible and must not discard confirmed writes. |
| Exit status → supervisor | systemd/scripts branch on the code. |
