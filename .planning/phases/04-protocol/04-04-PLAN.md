## Artifacts this phase produces

This plan adds: `SUPKV_STARTUP_GATE_EMPTY` / `--startup-gate-empty`, `defaultStartupGateEmpty`, `config.startupGateEmpty`, `errStartupGateRange`, `checkStartupGates`, the empty-vs-data gate selection, the `ListedKey: adapter.ListedKey` wiring, and `emptyGateArg` in the stand harness.

<objective>
Give an empty-disk node its longer wait and wire the whole parameter end to end, including the harness rule that keeps the frozen R-03 test green.

Purpose: 14.6/ADR 0006 says a returning or joining node with no data must wait longer than a node with data, because it has nothing local to answer with. The frozen stand test names only `--startup-gate=30s`; if the harness appends an empty-gate default of 1 s, the replaced node opens under the closed-side assertions and the test races. The derivation rule is therefore part of the acceptance, not a convenience.
Output: the flag/env/default/validation/selection, the adapter's `ListedKey` wiring, the harness derivation, the 14 test-site adaptations, and the stand proofs.
</objective>
