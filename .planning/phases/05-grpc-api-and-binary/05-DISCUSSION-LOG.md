## wait_for_replication

| Option | Description | Selected |
|--------|-------------|----------|
| Агрегат | acked=true/false + acked/total | ✓ |
| По-пирно | видно кого не дождались, но раскрывает топологию | |

| Option | Description | Selected |
|--------|-------------|----------|
| Per-request + дефолт | поле RPC, дефолт из конфига (wait_timeout) | ✓ |
| Только конфиг | клиент не может ждать дольше дефолта | |

| Option | Description | Selected |
|--------|-------------|----------|
| Снимок пиров | известных на момент записи; новые Hello не расширяют | ✓ |
| Динамически | появившийся за время ожидания тоже должен подтвердить | |

| Option | Description | Selected |
|--------|-------------|----------|
| Успех при 0 пиров | одиночный узел — валидная конфигурация | ✓ |
| Неудача при 0 | сигнал «репликации нет», но одиночный узел всегда «не реплицирован» | |

**User's choice:** все четыре решения выше
**Notes:** отчёт принципиально агрегатный — топология кластера не раскрывается через API

## List under prefix

| Option | Description | Selected |
|--------|-------------|----------|
| Полный список | один RPC, сортировка, без пагинации (объём — тысячи ключей) | ✓ |
| Пагинация | курсорная защита от разрастания, два RPC на большой список | |

| Option | Description | Selected |
|--------|-------------|----------|
| Только ключи | List отвечает «что есть», значение — через Get | ✓ |
| Ключи+значения | один RPC даёт всё состояние префикса, ответ тяжелее | |

| Option | Description | Selected |
|--------|-------------|----------|
| Без tombstones | живое состояние, не аудит | ✓ |
| С tombstones | видно историю, потребитель обязан фильтровать | |

| Option | Description | Selected |
|--------|-------------|----------|
| Пустой = всё | List без параметров перечисляет всё состояние | ✓ |
| Ошибка | InvalidArgument при пустом префиксе | |

**User's choice:** все четыре решения выше
**Notes:** контраст с Watch намеренный: List — перечисление живого состояния, Watch — полный поток изменений включая удаления

## Binary and configuration

| Option | Description | Selected |
|--------|-------------|----------|
| SUPKV_ префикс | SUPKV_NODE_ID, SUPKV_BIND_ADDR… — без коллизий | ✓ |
| Без префикса | короче, но легко сталкивается с окружением | |

| Option | Description | Selected |
|--------|-------------|----------|
| Флаг > env > дефолт | ближайшая инструкция выигрывает | ✓ |
| Env > флаг | режим «конфиг в окружении» | |

| Option | Description | Selected |
|--------|-------------|----------|
| version+commit+go | ldflags-инъекция; достаточно для поддержки | ✓ |
| Только version | не видно кем/чем собрано | |

| Option | Description | Selected |
|--------|-------------|----------|
| Финальный дамп | закрыть gRPC, остановить репликацию, финальный дамп с подтверждением | ✓ |
| Без финального | просто остановиться, данные добираются репликацией | |

**User's choice:** все четыре решения выше
**Notes:** SIGTERM-контур важен для systemd: подтверждённые записи не остаются только в памяти
