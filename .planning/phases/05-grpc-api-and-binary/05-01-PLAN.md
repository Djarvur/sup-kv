## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| gRPC client → SupKV server | Untrusted-length (bounded by 4 MiB default) client input crosses into handlers over the trusted LAN |
| handler → persist.Engine | Validated requests cross into the decision core |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering | SupKV server (unauthenticated RPC surface) | medium | accept | v1 accepted limitation per docs/IDEA.md §Trust model (trusted LAN, no auth/encryption); DOCS-02 restates prominently in Phase 7; do not bolt on auth here |
| T-05-02 | DoS | Set/List handlers (oversized requests) | medium | mitigate | Keep grpc default 4 MiB recv cap; value_max_bytes rejects oversized values with InvalidArgument via storage.ErrValueTooLarge mapping; A6 documents MaxSendMsgSize as the growth knob |

| T-05-SC | Tampering | go module installs (grpc v1.85.0, protoc-gen-go-grpc v1.6.2) | high | mitigate | Modules fetched from proxy.golang.org (sumdb-verified) and empirically probe-built/run this session (RESEARCH Package Legitimacy Audit, all OK); versions pinned in go.mod; no npm/pip/cargo coverage needed — Go module proxy + checksum DB is the legitimacy mechanism |
