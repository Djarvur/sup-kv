## Artifacts this phase produces

Consolidated list for the whole phase (later plans add to it in their own sections). This plan creates:
`storage.RecordsEqual`, `storage.Store.MergeChanged`, the content branch in `storage.Store.join`, the content-aware equal-version branch in `repl.Core.applyRemote`, `persist.Engine.ApplyRemote`'s `changed` decision, and `docs/adr/0012-equal-version-tiebreak.md`.

<objective>
Resolve equal-version-different-content deliberately and deterministically — PERSIST-07 — at both the store merge and the wire, and record the deviation in ADR 0012.

Purpose: the Spec's random 46-bit version tail was replaced by zero filler (S-HLC-07), so two replicas can hold the same version with different content after disk loss plus clock rollback. Today the store silently no-ops such a merge and the replication core Acks every equal version before consulting the store, so a store-only fix would be dead code and the replicas would diverge forever. The `(version, content)` law makes the outcome a pure function of the records, preserving byte-identical dumps and same-seed replay.
Output: `RecordsEqual` and `MergeChanged`, the join law, the core's equal-version branch, the engine's `changed` decision, the rewritten old-law tests, and ADR 0012.
</objective>

## Scope rationale

Nine files, one law applied at three sites that cannot ship separately: the store's join, the
core's equal-version branch and the engine's dirty decision (a store-only change is unreachable
dead code — the core Acks every equal version before consulting the store). The three storage
test files are rewrite-in-place of assertions that encode the old no-op law; the ADR is the
decision record the registry plan consumes. Splitting would leave the law half-wired.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| peer → replication core | An equal-version record can come from any peer and carries attacker-chosen content. |
| store → dump/replay | The winner must be a pure function of the records, or dumps and same-seed replays diverge. |
