## Artifacts this phase produces

Consolidated list for the whole phase (later plans add to it in their own sections). This plan creates:
`persist.DecodeStats` with `Checksum`, `Version`, `ValueLimit`, `Malformed` and `Total()`; `header.RecordCount`; `maxDumpLineBytes`; the bounded `readLine`/`readRecordLine` helpers; the per-class `decodeRecord` return; the `decodeClass` vocabulary; and the census/legacy rules in the codec contract.

<objective>
Turn the dump grammar into a self-describing format with a completeness census and line-isolated recovery — PERSIST-03 — and split the discarded-record counter into the four classes PERSIST-10 and the load report need.

Purpose: today one raw JSON syntax error poisons `json.Decoder` for the rest of the file (verified probe), so 44 % of single-byte corruptions reject the whole generation; a cut exactly at a line boundary is indistinguishable from a complete file. The format carries `format_version: 1` plus an additive `record_count`, the reader walks bounded lines with `ReadSlice` and `json.Unmarshal` per line, and a header count mismatch or an unterminated unparseable tail is the only whole-generation fault a v1.1 file can raise.
Output: the header field and writer count, the line-oriented decoder, the four-class stats, the legacy read path, and the updated codec/fuzz tables.
</objective>
