<objective>
Bound every blocking engine call — PERSIST-08 — with an explicit unconfirmed outcome and an honest RPC/shutdown story.

Purpose: a hung fsync currently parks `Set` on `<-w.done`, `flush` on its reply, and the binary's shutdown on both `Flush` and `engineDone`, so SIGKILL is the only exit. The confirmation wait gets `ConfirmTimeout` (10 s) with a single-claim waiter protocol, `FlushTimeout` bounds snapshots and the final dump, and the binary abandons a stuck goroutine at process exit instead of hanging. A timed-out write is installed and must replicate, so the RPC totality branches and `mapError` learn the new class.
Output: `ErrUnconfirmed`, the timeout/claim protocol, `FlushTimeout`, the bounded shutdown, the RPC mapping/totality, the unconfirmed counter, and the virtual-time proofs.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| engine → RPC client | A write can be installed but not yet durable; the RPC must not claim durability. |
