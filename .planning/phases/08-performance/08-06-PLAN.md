<objective>
Structurally remove the `freeUDPPort` pick-then-bind class (F-4) and the port-contention flakes it causes (F-5's bind half): three packages still pick a port from the kernel's ephemeral pool with a throwaway `:0` bind and bind the real socket later, while only `internal/stand` uses a private window below the ephemeral range. Move that allocator into `internal/testutil`, partition it into per-package bands, and adopt it everywhere, deleting the duplicate registries.

Purpose: D-07 requires the class "structurally removed", not muted. An in-process registry cannot coordinate separate test processes, so disjoint bands are the only construction that makes cross-process collisions impossible; claim-while-held closes the sibling window that survives inside one process.
Output: `internal/testutil/ports.go` (+ tests), four package wrappers, two deleted registries, and a corrected flake-class note in `Makefile`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Test process → kernel port space | A picked port is advertised to a child process or an adapter; between pick and bind another process can take it. |
| Test package → test package | Test binaries run as separate processes, so only disjoint bands can prevent cross-package collisions. |
| Host sysctl → allocator | A narrowed ephemeral range could move foreign sockets into the private window. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-14 | Denial of service | port-band squatting by a foreign process | medium | mitigate | Claim-while-held plus a 32-candidate bounded retry; a foreign holder causes a re-pick, never a false pass. |
| T-08-15 | Repudiation | a collision reported as a product failure | medium | mitigate | The sysctl assertion turns a broken assumption into a named environment error; the Makefile note and the summary record the accepted residue. |
| T-08-16 | Tampering | two packages silently sharing a band | high | mitigate | Bands are disjoint constants with a disjointness test; the duplicate registries are deleted so no private window can drift. |
| T-08-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package is installed; `net`, `testing`, `math/rand` are standard library. |
</threat_model>
