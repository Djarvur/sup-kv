<objective>
Finish XPORT-02 where it actually stops: the core still scans the whole pending map twice per local write (`trackedVersion`, `removeSupersededLocal`) and once per inbound `DataReplication` (`applyRemote`'s displacement loop), so a growing unacked set makes the notification path O(n). Add the per-key `pendingByKey` index, rewrite those three paths to read only that key's entry, and add the deterministic `PendingVisits` counter the phase's flatness gates read.

Purpose: PERF-05 requires absent-peer write latency to stay near live-peer latency; the scan is the structural reason it does not (03-REVIEW IN-02, still open with "Note for PERF/Phase 8"). The index is the fix, and `PendingVisits` is the load-independent proof 08-05's gates assert.
Output: `internal/app/repl/core.go` with `pendingByKey` and `PendingVisits`, and `internal/app/repl/pending_index_internal_test.go` proving the counts, the invariant and the equivalence.
</objective>

- **PERF-05 — the counter's completeness.** Assumption: the hot paths are exactly the five loops named in the research (`trackedVersion`, `removeSupersededLocal`, `applyRemote` displacement, `scanRetransmit`'s due loop, `handleHello`'s flush), so the counter measures the whole scan surface. Resolution: `TestCore_pendingVisits_structure` asserts the counter's loops by driving each path once and checking the exact delta; a future uninstrumented scan would evade it, which is why 08-05 keeps a paired wall-clock ratio in `make perf` as the backstop.
- **PERF-05 — behavior neutrality.** Assumption: the pending structures are observed only through the results stream, `PendingSnapshot`, `UnackedStats`, `MergeStats` and the counters, so an index that preserves those is invisible. Resolution: task 3 drives every production path through `HandleDatagram`/`Advance` and asserts the invariants after each step; the full repl, udprepl and grpcapi suites run under `-race`.
- **Decision fidelity:** D-05's "same fix as XPORT-02" is implemented; nothing in the dump policy, the wire format or the retransmission ladder changes. No deferred idea is implemented.
