## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env -> process config | SUPKV_LOG_* values cross from the operator environment into process behavior — malformed input must fail closed |
| UDP segment -> log volume | An attacker on the trusted segment can flood discard-class events into the log pipeline |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-6-05 | Information Disclosure | slog pipeline (tap bridge, discard events) | medium | mitigate | Logs must never carry record values or user data — the tap forwards the core's prebuilt metadata strings only (class, handles, node ids); TestLog_jsonDefault/TestDiscardLog_classes assert the attr surface; code review at PR gates the rest |
| T-6-06 | DoS | discard-class log events under datagram flood | medium | mitigate | Discard lines emit at Debug level (default info suppresses them) — the O(1) counters carry the signal; a bad-CRC flood cannot amplify into stderr spam at the default level |
</threat_model>
