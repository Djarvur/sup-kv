<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| network -> metrics/debug listener | Unauthenticated HTTP/TLS clients; pprof heap dumps and expvar are information-disclosure and CPU-DoS surfaces |
| operator env -> listener config | Cert/key/CA file paths and the bind address cross from the environment; incomplete or wrong config must fail closed |
| scrape -> core state | Scraper-triggered reads of adapter/engine state must be lock-free or copy-on-write (no scrape-induced stalls) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-6-07 | Information Disclosure | /debug/pprof/* and /debug/vars (heap dumps expose memory contents; expvar internals) | high | mitigate | Listener is opt-in with no default (D-01), mTLS with verified client certs available for non-loopback exposure (D-02), one listener for the whole surface (D-03); plaintext mode documented as loopback/debug-only |
| T-6-08 | Spoofing | metrics TLS listener | medium | mitigate | crypto/tls defaults plus explicit MinVersion floor tls.VersionTLS12; no custom ciphers; TestMetricsTLS_required proves unauthenticated handshakes fail |
| T-6-09 | DoS | pprof profile endpoints (CPU burn per request) | medium | accept | Same opt-in + mTLS gate as T-6-07 bounds who can request profiles; residual plaintext-loopback exposure is the operator's deliberate debug choice per D-02 — accept with documentation (Phase 7 ops docs restate it) |
| T-6-10 | Tampering | cert-triple validation order | medium | mitigate | Validation runs before any bind (Pitfall 8) — an incomplete set can never reach LoadX509KeyPair with empty strings; TestMetrics_incompleteCertSet pins exit 2 naming all three envs |
</threat_model>
