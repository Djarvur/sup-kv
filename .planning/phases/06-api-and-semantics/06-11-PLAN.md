<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Peer datagrams → Ack handling | Any node can send an Ack for any `(key, version)`; the wait report must not trust a stranger. |
| Handler goroutine → adapter tracker | Cross-goroutine resolution by channel close and per-tracker mutex. |
| Discovery flush → pending entry | A new peer's arrival must not widen an existing promise. |
