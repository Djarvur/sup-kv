<objective>
Ship a consumer proof for the public wire contract: a standalone `examples/client` Go module that builds in CI against `github.com/Djarvur/sup-kv/api/supkvapi/v1`, exercises the RPCs a consumer actually uses (write-with-wait, read, paginated list, one watch event), and documents that the last-read-value file pattern belongs to the consumer's library, not the server.

Purpose: APIS-06's acceptance requires the generated code to be usable from another module. A nested module with `replace ../..` is the cheapest cross-module proof and catches any accidental `internal/` dependency in the public package.
Output: `examples/client/{go.mod,go.sum,main.go,README.md}`, a `make client-example` target, and a `client-example` CI job.
</objective>
