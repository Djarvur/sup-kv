<objective>
Make error handling total and path-free: one ordered mapping table over every sentinel and failure class, a constant `Internal` fallback that logs the detail, adapter-side classification for snapshot create failures, and a test that walks the RPC matrix rejecting path shapes in every returned status message.

Purpose: A-03 — today the `%v` fallback leaks the configured filesystem path for a missing snapshot, `ErrNoDump` has no case, and `CreateSnapshot` bypasses the save classifier. Totality is structural: whatever the error, a constant message crosses the wire.
Output: the rewritten `mapError`, classified `CreateSnapshot`, `errors_test.go` (RPC matrix), and `errors_internal_test.go` (mapping table + log-capture test).
</objective>
