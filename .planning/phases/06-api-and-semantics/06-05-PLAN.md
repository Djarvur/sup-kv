<objective>
Turn `List` into keyset pagination over a live key→version view: bounded default/maximum page sizes, an opaque position token, a byte budget that keeps a page's cost independent of the store's total value bytes, values only for the page's entries, and an empty next token as the end signal.

Purpose: A-02 — today `List` calls the full `Records()` snapshot (deep-copying every value) and returns one unbounded response. The new view copies no values; the page copies only what it returns.
Output: `Store.LiveVersions`, `Engine.LiveVersions`, `internal/grpcapi/list.go` with the page algorithm and constants, the rewritten `List` handler, and the pagination/cost test matrix.
</objective>

Probe rows owned by this plan (specless fallback, unresolved):

- **APIS-02 (boundary) — page sizes and the budget edge.** Assumption: page_size 0 → default 64, >256 → clamp to 256, <0 → InvalidArgument; a page includes at least one entry even if that entry alone reaches the budget; the token is the last examined key so a skipped tombstone cannot stall progress. Resolution: table tests for 0, 1, 256, 257, -1, and a full-budget page.
- **APIS-02 (empty) — empty/single/null input.** Assumption: an empty store, an empty prefix, a single key, and an empty live value all behave as ordinary pages (empty response with an empty token for the empty store; one record with an empty value for the single key). Resolution: explicit cases in the pagination test.
- **APIS-02 (ordering) — equal elements.** Keys are unique in the map, so equal-element ordering is vacuous; the order is byte-wise ascending and stable across pages. Resolution: the multi-page test asserts a strict ascending, duplicate-free walk.
- **Decision fidelity:** D-02 chose keyset pagination with bounded pages and values only for the page. No deferred idea is implemented.
</assumptions>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → List | `prefix`, `page_size`, and `page_token` are untrusted input. |
| Store → response | A page copies only the selected values; the view copies no values. |
| Token → page position | A forged token crosses into the page seek. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
