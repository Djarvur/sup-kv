<objective>
Turn `List` into two truthful modes over one live key→version view: page_size unset/0 keeps the legacy all-keys, keys-only listing (the frozen R-01 contract), while page_size > 0 returns a bounded page of records with an opaque position token, a byte budget that keeps the page's cost independent of the store's total value bytes, and an empty next token as the end signal.

Purpose: A-02 — today `List` calls the full `Records()` snapshot (deep-copying every value). The new view copies no values; the legacy path copies only keys, and the paged path copies only what it returns. D-02's keyset pagination lives on the page_size > 0 path; the unset/0 path cannot be paginated without breaking the frozen single-call listing, so it stays the documented legacy shape and never carries values.
Output: `Store.LiveVersions`, `Engine.LiveVersions`, `internal/grpcapi/list.go` with both paths and the constants, the rewritten `List` handler, the pagination/cost test matrix, and the paged nightly poll in `internal/stand/stand_test.go`.
</objective>
