## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test output → runner | The runner parses `go test -json` events; the parsed stream is untrusted input (test output) consumed by CI logic |
| expectation table → CI verdict | The in-repo TSV decides pass/fail; a tampered row could mask a missing red |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-2-01 | Tampering | scripts/red-runner event parsing | medium | mitigate | Parse only the JSON events of the exact `go test` command the script spawned; use python3 stdlib json (no eval, no shell interpolation of output); unknown/missing names are errors, not silent passes |
| T-2-02 | Tampering | scripts/red-expectations.tsv | medium | mitigate | Table is in-repo and reviewed; runner errors on both a missing FAIL and an unexpected skip so removing a row or flipping it to green cannot mask a defect silently |
| T-2-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero-install phase (Package Legitimacy Audit: no external packages); no install steps exist to gate |
</threat_model>
