## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Unit → operator host | A unit with wrong paths, a restart-loop on usage errors, or undocumented flags breaks production hosts. The consistency test + systemd-analyze are the boundary checks. |

| CI → ruleset | Changing the gate matrix changes check-run contexts and silently breaks branch protection. The byte-identical-names constraint is the boundary check. |
