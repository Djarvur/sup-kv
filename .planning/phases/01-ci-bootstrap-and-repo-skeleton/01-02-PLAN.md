## Phase Goal

Quality gates and the enforced repo skeleton exist before any feature code, so every subsequent change lands inside the architecture and behind a red-light-blocking gate.

*(This plan delivers the goal's remote half: the first commit travels the full pipeline — feature branch, PR, gate matrix on all four OS/arch cells, merge.)*
