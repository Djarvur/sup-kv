## Artifacts this phase produces

See 03-01-PLAN.md for the consolidated phase list. This plan adds: the shrunk `repl.StateStore` interface, `listingChunks` built from `Versions()`, `handleDataRequest` via `Lookup`, `handleDataSync` via per-entry `Version` + `Lookup`, `internal/app/repl/bench_test.go` with `BenchmarkHandleDataRequest`, `BenchmarkHandleDataSync` and `TestCore_keyCountCostFlat`.

<objective>
Point the replication core at the cheap store view and prove the inbound handlers stop paying for unrelated store size.

Purpose: XPORT-06 requires `DataRequest`/sync-chunk handling independent of foreign records; today every handler call deep-copies the whole store. This plan consumes the view landed by 03-02 and shrinks the consumer-side interface so the old path cannot silently return. It implements locked decision D-08's core-consumption half.
Output: core handlers on the view, a compile-enforced interface without `Records`, every test adapter updated, and a benchmark-ratio gate.
</objective>
