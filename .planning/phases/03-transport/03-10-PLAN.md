## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| kernel read path → node | Read errors can arrive at any time; a bad one must not kill the loop |
| host port → process identity | A second process binding the same port could hijack traffic |
| operator bind address → broadcast reception | A non-wildcard bind silently loses broadcasts |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-3-33 | Availability / integrity | silently dead read loop while Hello keeps broadcasting | high | mitigate | ErrClosed-only exit; other errors counted, logged rate-limited, backed off; the counter is exposed for metrics; fake-conn test |
| T-3-34 | Spoofing | second process sharing the port via SO_REUSEADDR | high | mitigate | Production never sets it; duplicate bind fails with EADDRINUSE (adapter + binary tests); test-only explicit option |
| T-3-35 | Misconfiguration / Repudiation | non-wildcard bind silently receiving no broadcasts | high | mitigate | One explanatory WARN naming the host and the limitation; never silent |
| T-3-36 | Denial of Service | read-error log flooding / spin | medium | mitigate | Rate-limited log plus 100 ms backoff; counter is the reliable signal |
| T-3-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero-install phase; no module change |
</threat_model>
