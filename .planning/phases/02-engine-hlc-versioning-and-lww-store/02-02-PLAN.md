<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Arbitrary 16-byte versions → Unpack/Compare/Merge | From Phase 4, remote records carry versions off the wire; every version operation must be total over all bit patterns |
| Adversarial wall clock → Clock | The injected now func is the single seam; correctness must survive any jump pattern (D-02) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-03 | DoS | RecordVersion.Unpack/Compare on arbitrary bit patterns | medium | mitigate | Unpack/Compare are pure masking arithmetic with no panic path; TestVersion_unpackTotal feeds 1000 seeded-random raw 16-byte values through them |
| T-02-04 | Tampering / Elevation of Privilege | Forged future timestamps winning every merge | medium | accept | Trusted-segment trust model is a documented accepted limitation (docs/IDEA.md "Trust model"); no auth in v1 by design; the drift signal (VERS-05) makes the condition observable; HMAC is SEC-01 (v2) |
| T-02-SC | Tampering | Package installs (new modules) | high | mitigate | Zero installs this phase (D-04); property tests are stdlib-only by locked decision; no install commands in any task |
</threat_model>

## Flagged Assumptions (Edge Probe — unclassified rows, intentionally unresolved)

1. **VERS-01 (probe row unclassified):** filler bits are zero-filled per node (research A2) — ordering and uniqueness rest on (l, counter, NodeID), not on the filler.
2. **VERS-02 (probe row unclassified):** uniqueness assumes distinct NodeIDs across nodes; a duplicate node_id is a configuration error detected in Phase 4 (REPL-08), not by the engine.
3. **VERS-05 (probe row unclassified):** drift assumed to fire in BOTH directions with the sign available (research A4) — positive when the HLC runs ahead, negative on a forward wall-clock jump beyond DriftWarn; the locked D-02 text names only the wall-clock-ahead case, which this reading covers.
