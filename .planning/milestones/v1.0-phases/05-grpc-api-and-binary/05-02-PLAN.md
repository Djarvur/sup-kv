<objective>
Add the two replication read seams the gRPC layer needs but the core lacks: a first-DataSync-arrived signal (the startup gate's sync half, API-04) and an Acked set in the pending tracking (the honest wait_for_replication report, API-05), each mirrored cross-goroutine by the udprepl adapter.

Purpose: RESEARCH gap analysis verified that repl.Core records neither state today: WaitingOn alone cannot distinguish "peer Acked" from "peer evicted by peer_timeout" (both shrink the wait-set), which would corrupt the D-08 aggregate report; and no first-sync signal exists for the gate. Everything in this plan is purely additive inside existing packages.
Output: Core.SyncArrived/PendingInfo.Acked in internal/app/repl, and Adapter.SyncArrived/PendingCopy atomics in internal/udprepl.
</objective>
