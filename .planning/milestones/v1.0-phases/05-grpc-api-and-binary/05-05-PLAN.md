Pinned algorithm, with consts waitPoll = 5ms and waitAppear = 500ms (load-bearing comments): (1) total is uint32(KnownPeers()) captured once at write time — peers discovered during the wait never extend the awaited set (D-10); nil KnownPeers/PendingCopy seams mean zero peers.
