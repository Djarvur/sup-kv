## Подтверждение записи (write confirmation)

| Option | Description | Selected |
|--------|-------------|----------|
| Ожидание в ядре | Ядро хранит границу подтверждённых версий + примитив ожидания «дамп догнал версию X»; без обратных вызовов | ✓ |
| Ожидание в адаптере | Ядро только данные; ожидание и уведомления собирает сервисный слой | |

**User's choice:** Ожидание в ядре (рекомендовано)

| Option | Description | Selected |
|--------|-------------|----------|
| 1 с | Щедрый запас при ~1000 записях/с | ✓ |
| 500 мс | Тighter латентность, крупнее дампы | |
| 200 мс | Почти без коалесцирования | |
| Решай сам | Имя и значение выберет планировщик | |

**User's choice:** 1 с (рекомендовано). PERS-03: дамп обязан начаться не позже N после самой старой неподтверждённой записи.

| Option | Description | Selected |
|--------|-------------|----------|
| Сразу ошибка | Все ждущие получают Unavailable; запись остаётся в памяти; следующий дамп — по изменению или таймеру | ✓ |
| Авто-повторы | Повторы до успеха, ждущие висят до максимума | |

**User's choice:** Сразу ошибка (рекомендовано)

## Формат файла (dump format)

| Option | Description | Selected |
|--------|-------------|----------|
| Объект, строка = запись | Один JSON-объект: шапка с версией формата, записи по строке | ✓ |
| Построчный JSONL | Каждая строка — JSON; файл в целом не валидный JSON | |
| Единый JSON-объект | Свёрнутый/красивый JSON целиком | |

**User's choice:** Объект, строка = запись (рекомендовано)

| Option | Description | Selected |
|--------|-------------|----------|
| CRC32 | Единообразно с репликацией, в рамках модели доверия | ✓ |
| SHA-256 | Криптостойко, медленнее, избыточно для модели доверия | |

**User's choice:** CRC32 (рекомендовано)

| Option | Description | Selected |
|--------|-------------|----------|
| Сортировать по ключу | Стабильный порядок, побайтово сравнимые поколения | ✓ |
| Без сортировки | Порядок внутренней карты, несравнимые дампы | |

**User's choice:** Сортировать по ключу (рекомендовано)
